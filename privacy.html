EmailTriage Privacy Policy

Last updated: 2 November 2026

EmailTriage is a personal, local-first application built and used by its developer to triage their own Gmail inbox. It is not offered to the public.

Data accessed

EmailTriage requests a single Google OAuth scope: https://www.googleapis.com/auth/gmail.readonly. This allows it to read email messages and metadata (sender, subject, date, body). It cannot send, delete, or modify any email.

How data is used

Emails are read only to classify their importance. Classification is performed entirely on the user's own computer by a locally running language model. Email content is never sent to any external AI service or third-party server.

How data is stored

  • OAuth tokens are stored on the user's own computer, encrypted using ASP.NET Core Data Protection, and are never written in plain text.
  • Classification results and limited email metadata may be stored in a local database on the same computer. Nothing is stored on any remote server operated by EmailTriage.

How data is shared

Data is not sold, rented, or shared with anyone. The only data that leaves the user's computer is a short alert for important emails (such as the sender, subject, and a brief summary), sent to the user's own Telegram account via the Telegram Bot API.

Google API Services User Data Policy

EmailTriage's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token files and database removes all stored data.

Contact

Questions can be raised via the project's GitHub repository.
